# Specify the RFC registry

## Goal
Write `docs/specs/rfc-registry.md`: one machine-readable data model feeding both syntax codegen and the conformance database.

## Acceptance
- [ ] The data model covers syntax artifacts (headers, compact forms, option tags, URI parameters, response codes, event packages), normative requirements, RFC dependencies, and profile compatibility.
- [ ] One nontrivial RFC (5626) is captured as the worked example: option tags, URI parameters, components, dependencies, profile applicability.
- [ ] The registry format and its versioning against the sipx kernel are decided.
